# Paborito Kong Serye: Arcane

> Isang pambihirang animated series mula sa Netflix.

## Mga Pangunahing Tauhan
* **Vi** - Ang matapang na nakatatandang kapatid.
* **Jinx** - Ang magulong imbentor.
* **Caitlyn** - Isang Enforcer mula sa Piltover.

### Bakit ko ito nagustuhan?
1. *Magandang animation style* na 2D at 3D art.
2. Napakalalim ng kwento ng dalawang siyudad.
